          /^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^\
         | options:                                                                  |
         |     -d, --directory DIR     Directory of the animals                      |
         |     -h, --help              Display This Text                             |
         |     -e, --escape            Allow escape sequences (\n, \t etc...)        |
         |     -o, --offset NUM        Offset the text bubble by NUM (Default is 10) |
